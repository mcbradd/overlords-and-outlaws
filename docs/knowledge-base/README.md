## Terms

| Term | Source meaning |
|---|---|
| Dynasty / bloodline | A network of related or connected historical figures; the structure through which power is held. |
| Overlord | A face-up Royal committed to a declared dynasty; visible authority and an attack surface. |
| Outlaw | A card concealed in hand; potential expansion, bargaining, seizure, or other leverage. This is a state, not a separate criminal faction. |
| Founder | An anchor that shapes how a dynasty begins and where collapse begins, rather than granting supremacy. |
| Royal | A historical person belonging to a dynasty archive. |
| Inheritance | The pre-declaration 3–2–1 passing draft. |
| Declaration | Revealing at least three matching Royals to establish visible dynastic authority. |
| Interregnum / Interregna | An event / events representing historical disruption, never a person. |
| Eudoxia di Rossi | The Witness: a non-player threat whose paintings can complete before any dynasty wins. |
| Archive | A historically grounded collection introducing both people and distinct political pressures. |
| Outsider | A proposed future component for people outside bloodline architecture; not an Interregnum. |

## Central invariants

Exposure creates authority and vulnerability. Concealment preserves possibility. Marriage buys access with vulnerability. History belongs to no player. Eudoxia can defeat everyone. Holding power matters as much as acquiring it. Expansion must introduce meaningful political differences rather than cosmetic reskins.
